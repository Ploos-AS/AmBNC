# M1 — Upstream IRC session

M1 establishes the persistent upstream side of AmBNC.

Implemented:

- `bsdsocket.library` lifecycle and IPv4 TCP connect/disconnect;
- bounded IRC line framing with a 510-byte payload limit;
- PASS/NICK/USER registration;
- automatic PING/PONG handling;
- disconnect detection and bounded reconnect backoff: 1, 2, 4, 8, 16, 30 seconds;
- Ctrl-C shutdown;
- CLI contract: `AmBNC HOST PORT NICK [USER] [PASS]`;
- Bebbo/68000 build baseline using `-m68000 -mcrt=nix20`.

The network and IRC modules are separated from the upstream session so M2 can add the downstream listener and bidirectional relay without replacing the upstream implementation.

`make check` is a static repository gate only. Native Bebbo compilation and FS-UAE/AmigaOS runtime qualification remain separate qualification steps.
