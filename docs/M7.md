# M7 — Modern IRC extensions

Status: IMPLEMENTED, NOT RUNTIME-QUALIFIED.

M7 adds modern IRC negotiation to config-mode multi-network sessions while preserving the classic AmigaOS 2.04+/68000 baseline.

## CAP

Each `[NETWORK name]` section accepts `CAP=YES|NO`. When enabled, AmBNC starts registration with IRCv3 capability discovery and ends CAP negotiation cleanly when no requested capability remains.

## SASL PLAIN

`SASL_PLAIN=YES` enables SASL PLAIN negotiation. It automatically enables CAP. The configured `USER` is used as the SASL identity and the existing `PASS` value is used as its secret. A missing PASS is rejected by the config parser when SASL PLAIN is enabled.

The implementation handles capability advertisement, capability request/acknowledgement, authentication challenge, bounded Base64 encoding, success numeric 903 and failure numerics 904-907.

## TLS strategy

`TLS_MODE=PLAIN` means AmBNC opens the configured host/port directly as ordinary TCP.

`TLS_MODE=PROXY` records that the configured host/port is expected to be an external TLS termination endpoint. AmBNC itself still speaks ordinary TCP to that endpoint. This keeps certificate validation and cryptography outside the 68000 process and is the recommended M7 strategy for classic hardware.

Native AmiSSL/TLS is intentionally not implemented in M7.

## M6 integration

The existing M6 multi-network loop is kept intact. `networks.h` redirects the registration and state-observation calls through M7 wrappers in `networks.c`, which maintains bounded per-network modern-IRC negotiation state. The standalone single-session CLI remains unchanged.

## Qualification

This milestone has not yet been compiled with the Bebbo toolchain or qualified under FS-UAE/AROS or real AmigaOS. Runtime qualification remains part of M8.
